# Доверие к алгоритму

Эмпирическое исследование взаимодействия человека и ИИ при решении вероятностных задач с N-исходами. Материалы готовятся для журнала «Юный учёный».

Веб-приложение — экспериментальная среда на базе расширенного парадокса Монти Холла (10 дверей). Участник выбирает дверь, часть пустых открывается, затем принимает финальное решение. После завершения выдаётся проверочный код для крауд-платформы. Повторное прохождение на одном устройстве недоступно.

Стек: HTML, CSS, JavaScript. Хостинг – GitHub Pages. Ответы записываются в Google Таблицу через Apps Script; URL приёма данных задаётся в `js/config.js`.

Локальный просмотр:

```bash
python3 -m http.server 8080
```

Затем откройте http://127.0.0.1:8080.
