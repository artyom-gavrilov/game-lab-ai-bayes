# Данные эксперимента

Файл `results.csv` содержит результаты всех 506 завершённых прохождений, собранных
27–28 августа 2026 года на краудсорсинговой платформе «Яндекс Задания».

Данные обезличены: участник опознаётся только случайным номером сессии, никаких
персональных сведений не собиралось. Столбец с кодом завершения, который
использовался для оплаты заданий, из открытой версии удалён.

## Описание столбцов

| Столбец | Значение |
| --- | --- |
| `Timestamp` | Дата и время записи результата |
| `Session_ID` | Случайный идентификатор сессии (UUID) |
| `Group_ID` | Экспериментальная группа: `Group_A` — без совета, `Group_B` — ложный совет «50/50», `Group_C` — директивный совет, `Group_D` — совет с математическим обоснованием |
| `Winning_Door` | Номер двери с призом, 1–10 |
| `Initial_Door` | Дверь, выбранная участником изначально |
| `Alt_Door` | Вторая дверь, оставшаяся закрытой после того, как ведущий открыл 8 пустых |
| `Final_Door` | Дверь, выбранная окончательно |
| `Is_Switched` | 1 — участник сменил дверь, 0 — остался при первоначальном выборе |
| `Is_Win` | 1 — участник нашёл приз, 0 — не нашёл |
| `Reading_Time_MS` | Время в миллисекундах от появления совета до окончательного выбора |

Поскольку ведущий всегда открывает ровно 8 пустых дверей, закрытыми остаются
только `Initial_Door` и `Alt_Door`. Поэтому `Final_Door` всегда совпадает с одной
из них, а `Is_Switched` равно 1 тогда и только тогда, когда `Final_Door` равно
`Alt_Door`.
